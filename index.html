Publicador YouTube

O Publicador YouTube é uma ferramenta de uso pessoal que envia vídeos para o canal do YouTube do próprio dono da conta, usando a YouTube Data API v3.

O aplicativo só acessa a conta que o autorizou e só envia e gerencia vídeos desse canal. Ele não é oferecido a outros usuários.
